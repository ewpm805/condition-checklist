# Condition Checklist

Offline phone app (PWA) for move-in / move-out property condition checks with photos.
Built for East West Property Management. Inspection data and photos stay on the phone
(and later the company Google Drive); nothing is stored in this repository.

Install: open https://ewpm805.github.io/condition-checklist/ on the phone, then
Android Chrome: menu > Install app; iPhone Safari: Share > Add to Home Screen.
